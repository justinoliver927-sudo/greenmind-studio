  • HTML, CSS and JavaScript editing
  • Sandboxed browser preview
  • Local draft saving and file export
  • Create, open, rename and delete projects
  • HTML structure and duplicate-ID checks

  • Server-side AI coding assistant (requires private backend configuration)
